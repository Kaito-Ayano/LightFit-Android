# LightFit · 轻体 (Android, Java)

Low-pressure everyday health-recovery app. Personalized plans + posture self-check +
exercise library. Offline-first, AES-256-GCM local storage, 5 languages (zh/en/ru/kk/ko).

## Build
Open this folder in Android Studio (Hedgehog or newer). The IDE provisions Gradle 8.2
and Android SDK 34 automatically, then `Build > Build APK`.

Data sources: exercise catalog and UI strings are migrated from the LightFit web
edition (v8.2 / v8.4.3). Product requirements: see the English business plan in the
portfolio repository.
